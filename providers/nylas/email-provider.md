# Nylas Email Provider Placeholder

This provider will eventually implement the Email capability interface using supported Nylas APIs.

## Intended Responsibilities

- Authenticate through the approved Nylas flow.
- Send email.
- Search messages.
- Read threads.
- Reply to messages.
- Translate Nylas-specific data into AIHub Email capability models.

## Non-Goals For Skeleton

- No API credentials.
- No live Nylas calls.
- No local token storage.
- No synchronization process.
